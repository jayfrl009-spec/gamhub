# School Horror Roblox Starter

A simple starter kit built with Roblox parts—no external asset IDs needed.

## Install
1. Open the repository's **Code** page and choose **Download ZIP**.
2. Extract it.
3. Open Roblox Studio and create a **Baseplate**.
4. In **ServerScriptService**, add a Script named `MapBuilder`, then paste in `MapBuilder.server.lua`.
5. Add another Script named `NPCBehavior`, then paste in `NPCBehavior.server.lua`.
6. Press **Play**.

The map is generated during Play: a school hallway, lockers, classroom doors, spawn, exit prompt, and a creepy block-built student. This is a starter prototype, not a finished game.
